# Biblioteca

Aplicación de navegación para el taller de Expo Router.

## Ejecutar

```bash
npm install
npx expo start
```

Escanea el QR con Expo Go. Para abrir el login directamente, añade `/--/login` a la URL de desarrollo que imprime Expo CLI.

## Navegación

- Stack raíz para el Drawer, autenticación, detalle de libros y modal Acerca de.
- Drawer con Inicio y Ajustes.
- Tabs con Inicio, Favoritos y Perfil.
- Datos de ejemplo en `src/data/libros.ts`.
