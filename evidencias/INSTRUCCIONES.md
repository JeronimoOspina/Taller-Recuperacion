# Capturas de evidencia

Guarda las cuatro capturas solicitadas en esta carpeta. Para capturas reales desde Expo Go:

1. Ejecuta `npx expo start` y abre la app en Expo Go. Para mostrar directamente el login, abre la URL de desarrollo que imprime Expo CLI añadiendo `/--/login` (por ejemplo, `exp://<IP>:8081/--/login`); captura el marco azul claro con “Biblioteca” y el botón “Entrar”.
2. Entra, abre el botón ☰ del encabezado del Drawer y captura las opciones **Inicio** y **Ajustes** sobre las pestañas.
3. Cierra el Drawer, toca **Cien años de soledad** y captura el detalle con el título en el encabezado.
4. Regresa, abre la pestaña **Perfil**, toca **Acerca de** y captura el modal abierto.

Nombra las imágenes `01-login.png`, `02-drawer.png`, `03-detalle.png` y `04-acerca.png`. Esta carpeta contiene instrucciones; no contiene capturas simuladas.
